# Дизайн

## Принципы

- **Невидимость.** Окон нет, только иконка в трее, меню и короткие popup.
- **Подтверждение каждого действия.** После переключения или ошибки - popup и подсказка у иконки.
- **Одна клавиша.** Главный сценарий не требует мыши.

## Иконка трея (`create_image`)

Рисуется Pillow в коде, 64x64 RGB. `MicSwitcher.ico` в рантайме не используется, только для exe.

| Элемент | Форма | Цвет |
|---|---|---|
| Фон | Весь холст | `(30, 30, 30)`, почти чёрный |
| Плашка | Скруглённый квадрат 8..56, радиус 10 | `(60, 120, 220)`, синий |
| Капсула микрофона | Прямоугольник 28..36 x 18..36 | Белый |
| Низ капсулы | Круг 22..42 x 32..50 | Белый |
| Ножка | Прямоугольник 30..34 x 46..56 | Белый |

Подсказка иконки (`icon.title`) - последнее сообщение `report`.

## Popup (`PopupManager`)

| Параметр | Значение |
|---|---|
| Размер | Ширина 360, высота по тексту, не меньше 90 |
| Положение | Правый нижний угол: 20 от правого края, 60 от нижнего (над панелью задач) |
| Окно | Без рамки (`overrideredirect`), поверх всех (`-topmost`) |
| Фон | `#1f2937`, рамка 1px `solid` |
| Заголовок | Segoe UI 10 bold, белый, отступы 12 / 10 сверху |
| Текст | Segoe UI 10, `#e5e7eb`, перенос по 330 |
| Время показа | `max(1.5 с, timeout)`: 2-3 с для обычных сообщений, 4-5 с для предупреждений и ошибок |

Заголовок всегда `MicSwitcher`. На экране не больше одного popup: новый заменяет предыдущий. Несколько сообщений одного действия (старт, обновление списка, подключение устройств) склеиваются в один popup построчно (`report_all`).

## Меню трея

```text
Переключить микрофон  (ctrl+alt+m)
Переключить вывод  (ctrl+alt+o)
Профиль: <активный>  >  (•) Гарнитура  (ctrl+alt+1)
                        ( ) Колонки
                        -----
                        Следующий профиль  (ctrl+alt+p)
                        Сохранить текущее как профиль...
                        Удалить профиль  >  ...
-----
Микрофон  >  Включить Mic 1: <имя> / Включить Mic 2: <имя>
             -----
             Выбрать Mic 1  >  (•) устройство — интерфейс ...
             Выбрать Mic 2  >  ...
Вывод     >  то же для Out 1 / Out 2
Эквалайзер  >  Вывод     >  (•) Выкл / Бас / Чистый голос / Игры: шаги / Мягкий / свои
               Микрофон  >  (•) Выкл / Голос / Убрать гул / Радио / свои
               -----
               Открыть папку Equalizer APO  (или «Скачать Equalizer APO»)
-----
Показать текущие
Обновить список устройств
-----
[x] Автозапуск
-----
Открыть config.json
Перечитать config.json
Открыть лог
-----
Выход
```

- Главное действие - наверху: переключить микрофон, вывод, профиль. Настройка слотов спрятана в подменю.
- Хоткей пункта - в скобках после названия, если задан.
- Подпись устройства (`Device.label`): имя и интерфейс через «—», например «Микрофон — Realtek(R) Audio»; интерфейс не пишется, если совпадает с именем.
- Не выбранный слот подписан «не выбран», выбранный, но отключённый - «не подключен».
- Пустые списки - неактивный пункт: «Нет устройств», «Профилей пока нет».

## Панель настроек

Тёмная тема в цветах popup (`#111827` фон, `#1f2937` карточки, `#374151` поля, `#3c78dc` акцент), шрифт Segoe UI 10, ttk-тема `clam`. Окно не меньше 560x460, вкладки:

```text
MicSwitcher                                        Звук: Core Audio
[Устройства] [Профили] [Эквалайзер] [Настройки]
┌ Микрофон ───────────────────────────────────────┐
│ Сейчас: Mic 1, Headset — Jabra                  │
│ 1: [Headset — Jabra        v] [Включить]        │
│ 2: [Desk Mic — USB         v] [Включить]        │
│ [Переключить  (ctrl+alt+m)]                     │
└─────────────────────────────────────────────────┘
┌ Вывод ── то же для Out 1 / Out 2 ───────────────┐
```

- «Профили»: список (активный с «•», хоткей в скобках), «Применить» / двойной клик, «Удалить», хоткей профиля с «Записать» и «Назначить»; ниже - «Название» + «Сохранить» (подставляется «вывод + микрофон»).
- «Эквалайзер»: статус Equalizer APO и кнопка «Открыть папку» / «Скачать», пресеты вывода и микрофона, статус плагина RNNoise, порог голоса.
- «Настройки»: три хоткея с «Записать» (ждёт нажатие сочетания) и «Сохранить хоткеи», автозапуск, слежение за устройствами, config.json и лог.
- Каждое действие подтверждается тем же popup, что и из меню.

## Окно ввода

«Сохранить текущее как профиль...» открывает стандартный `simpledialog` tkinter «Название профиля:» с подставленным именем «<вывод> + <микрофон>». Отмена или пустое имя - ничего не сохраняется. Имя существующего профиля (без учёта регистра) - профиль обновляется, его хоткей сохраняется.

## Тексты

- Русский, коротко, с именем устройства: «Переключено на Mic 2: Микрофон», «Активен Out 1: Наушники».
- Профиль - заголовок «Профиль «Имя»» и по строке на устройство: «Вывод: Наушники», «Микрофон не подключен».
- Ошибки начинаются с «Ошибка ...» или «Не удалось ...» и содержат текст исключения.
