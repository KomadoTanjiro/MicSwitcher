# Требования к продукту

## Обзор

MicSwitcher - утилита для Windows в трее: горячими клавишами переключает микрофон и устройство вывода по умолчанию, профили меняют всё сразу, эквалайзер (через Equalizer APO) улучшает звук наушников и микрофона во всех программах. Каждое действие подтверждается всплывающим окном в правом нижнем углу экрана.

## Проблема

- Сменить микрофон или наушники в Windows - несколько кликов: «Параметры звука», устройство, «По умолчанию».
- Часто нужно прыгать между гарнитурой и колонками, настольным и встроенным микрофоном, иногда посреди созвона или игры.
- Сценарий («созвон», «игра», «стрим») - это сразу несколько настроек: вход, выход, эквалайзер.
- Эквалайзер в каждой программе свой или его нет; системного в Windows нет.

## Цели

1. Переключение одной клавишей из любого окна: отдельно микрофон, вывод, профиль.
2. Работает в любой программе, где выбрано устройство «По умолчанию»: Discord, Steam, Teams, OBS, игры.
3. Всегда видно, что получилось: popup и подсказка у иконки трея.
4. Ноль настройки на старте: конфиг и выбор устройств создаются сами.
5. Лёгкость: один exe без установщика, служб и внешних программ (кроме Equalizer APO для эквалайзера).

## Целевые пользователи

- Основной: автор. Windows, гарнитура и колонки, два микрофона, созвоны и игры.
- Шире: стримеры, геймеры, подкастеры, все, у кого несколько звуковых устройств.

## Ключевые понятия

| Понятие | Смысл |
|---|---|
| Вид устройств | Микрофон (`mic`, запись) или вывод (`out`, воспроизведение) |
| Слоты | Mic 1 / Mic 2, Out 1 / Out 2: между ними работает переключение. Хранятся в `config.json` как ID устройства Windows |
| ID устройства | Идентификатор Core Audio вида `{0.0.1.00000000}.{guid}`. Старые конфиги с ID SoundVolumeView переводятся автоматически |
| Текущий | Устройство по умолчанию для первой роли из `set_default_mode` (при `all` - Console) |
| Роль | Console, Multimedia, Communications. Какие менять, задаёт `set_default_mode` (по умолчанию `all`) |
| Профиль | Имя + микрофон + вывод + пресеты эквалайзера (+ свой хоткей). Пустое поле - не менять |
| Пресет | Набор команд Equalizer APO для вывода или микрофона: встроенный или свой из `eq_custom_presets` |
| Реализация звука | Core Audio (основная) или SoundVolumeView (запасная), выбирает `audio_backend` |

## Ключевые фичи

1. **Хоткеи**: `ctrl+alt+m` микрофон, `ctrl+alt+o` вывод, `ctrl+alt+p` следующий профиль, у профиля может быть свой. Пустое значение выключает хоткей.
2. **Меню трея**: переключить микрофон и вывод, профили (применить, следующий, сохранить текущее, удалить), подменю «Микрофон» и «Вывод» (включить слот, выбрать устройство в слот), эквалайзер, показать текущие, обновить список, автозапуск, конфиг, лог, выход.
3. **Профили**: сохранить текущее состояние под именем (окно ввода), применить из меню или хоткеем, перебирать по кругу.
4. **Эквалайзер и шумодав**: пресеты для вывода и микрофона (в том числе шумодав на плагине RNNoise), применяются к текущему устройству и переезжают за ним при переключении, в том числе если устройство сменили в настройках Windows.
5. **Автовыбор**: при старте и обновлении списка пустые или пропавшие слоты заполняются первыми доступными устройствами.
6. **Автообновление**: подключили или выдернули устройство - меню обновилось, popup «Подключен» / «Отключен».
7. **Автозапуск** через `HKCU\...\Run` с галочкой в меню.
8. **Уведомления**: собственное окно поверх всех, 1.5-5 секунд; одно действие - один popup.
9. **Лог** всех действий и ошибок в `mic_switcher.log`, ротация на 1 МБ.
10. **Без внешних программ**: устройства через Core Audio; SoundVolumeView нужен только как запасной вариант.

## Правила поведения

1. В двух слотах одного вида не может быть одно и то же устройство: выбор отклоняется с сообщением.
2. Переключение: если текущий = слот 1, включается слот 2; во всех остальных случаях - слот 1.
3. Одно переключение за раз: нажатие во время переключения и чаще раза в 0.3 с (для каждого вида отдельно) игнорируется.
4. Меньше двух активных устройств вида: предупреждение, выбор не меняется.
5. Профиль с отключённым устройством применяется частично: остальное включается, про отключённое - строка в popup.
6. Профиль без `eq_mic`/`eq_out` не меняет текущие пресеты.
7. Пресет выставлен, а Equalizer APO не установлен или нет плагина RNNoise для шумодава: предупреждение, остальные пресеты работают.
8. Настройки Equalizer APO пользователя не меняются, кроме одной строки `Include: MicSwitcher.txt` в `config.txt`.
9. Отключение устройства не меняет выбор слотов: гарнитура вернётся на своё место, в меню пока «не подключен».
10. Если Core Audio недоступен и рядом нет `SoundVolumeView.exe`, приложение не стартует: окно ошибки с инструкцией.
11. Повреждённый `config.json` откладывается в `config.json.broken` и создаётся заново.

## Вне рамок

- Больше двух устройств в цикле одного вида (для этого есть профили).
- Своё устройство для отдельной программы (Discord в гарнитуру, игра в колонки): в бэклоге.
- macOS и Linux.
- Программы, где устройство выбрано явно, а не «По умолчанию».
